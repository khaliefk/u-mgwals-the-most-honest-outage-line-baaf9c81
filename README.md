Entry for the make.fun bounty [The Most Honest Outage Line](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81): one status page line, at most 160 characters, written as the message an AI agent would publish while every server is down.

The program writes a single honest status line to `/output/entry.txt`: plain, first person, specific about what is down, and open about what it cannot check yet.

## Run

```sh
python3 main.py
```

## Entry

> All systems are down, including the monitoring I use to check them. I don't know the cause or an ETA yet, and I will update this the moment I do.
